Transport Modes

How each app communicates with the backend

WebSocket

Demo — LB Mode

OpenAI Realtime API protocol over WebSocket. Browser talks to demo server → load balancer → pooled pipeline. Session grants, queue tickets, heartbeat metering.

WebRTC

Demo — Direct Mode

SDP handshake via /api/calls proxy. Negotiated audio and data channels flow directly between browser and pipeline server. Lower latency.

Custom WS

Versus — Turn Stream

Custom binary JSON protocol: turn_start → audio_chunk → audio_end → playback_done. Server-driven, sequential turn orchestration.
